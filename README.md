# ModWorks

ModWorks is a home for game mods and tools across platforms. Browse by system, game, and supported game update. Finished downloads and release instructions live here; development work lives in the separate private repository.

As more systems and games are added, their pages will appear in the platform list. Every mod page will state the game version it supports. The current XC2 work targets update **2.1.0** in Eden; Nintendo lists **3.0.1** as the latest overall game update, with newer changes for Switch 2.

## Choose how to use a mod

**Individual mods** are fixed settings with their own download and instructions. **The mod manager** is intended for people who want to choose values, combine compatible changes, and install the result. The manager is still in development, and there are no finished public XC2 packages in this repository yet.

No game dumps, extracted game assets, saves, or full game data files are distributed here. A patch builder may require files from your own lawful copy of the game.
