**Installation:** each page links its build-specific cheat text file. Save that file as `815A2C19D1767896.txt` inside an add-on folder such as `Eden/user/load/0100AE00096EA000/<Mod Name>/cheats/`, enable the add-on in Eden, and restart the game. Download the raw text file rather than saving GitHub's HTML preview. Paths can differ if Eden uses a custom user directory.

Only use these with update 1.0.1 and the matching build ID. Do not combine mods that patch the same addresses; the pages call out known overlaps. These are original patch instructions, not game dumps or extracted assets.
