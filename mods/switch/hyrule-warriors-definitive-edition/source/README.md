# Hyrule Warriors: Definitive Edition source

This directory contains authored source, builders, technical notes, and test history for the gameplay-tested public mod families.

- Faster Apothecary confirmations
- Faster Badge Market confirmations
- Faster Bazaar
- Faster Blacksmith confirmations
- Faster Training results
- Immediate enemy loot
- Loot-quality development history
- EXP, material, and rupee multiplier histories
- PlayStation-prompt documentation and generation scripts

Install-shaped public downloads remain under [update 1.0.1 / Eden / individual](../1.0.1/eden/individual/README.md). Experimental camera, companion-AI, and incomplete instant-cutscene-skip work remain in the private repository. Extracted game files, saves, and original copyrighted assets are not included here.
