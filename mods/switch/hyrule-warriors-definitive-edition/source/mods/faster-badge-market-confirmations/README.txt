Faster Badge Market Confirmations v1.0.0

Game: Hyrule Warriors: Definitive Edition
Update: 1.0.1
Build ID: 815A2C19D1767896

Purpose
Speeds up the Badge Market's badge-creation and result animations to four times
their normal rate. The badge purchase itself, material costs, result state, and
menu logic are unchanged.

Installation
Copy this mod folder into Eden's per-game mod directory, then enable it in the
game's Add-ons menu. Restart the game after changing the enabled state.

Compatibility
This patch is specific to Hyrule Warriors: Definitive Edition update 1.0.1 and
the Build ID listed above.
