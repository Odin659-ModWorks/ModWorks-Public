Immediate Enemy Loot v1.0.0
Hyrule Warriors: Definitive Edition update 1.0.1
Build ID: 815A2C19D1767896

Spawns an enemy's generated loot as soon as the game registers the enemy's death.
The enemy can continue its normal death animation, but its valid drops no longer wait for that animation to finish.

Enable this folder in Eden's Add-ons menu, then restart the game.

This mod is independent of reward multipliers and loot-quality mods.
