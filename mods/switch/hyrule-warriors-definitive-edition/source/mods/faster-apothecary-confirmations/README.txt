Faster Apothecary Confirmations v1.0.0

Game: Hyrule Warriors: Definitive Edition
Update: 1.0.1
Build ID: 815A2C19D1767896

Purpose
Shortens the delay after creating an Apothecary mixture. The result effect is
reduced from 60 frames to 5 frames, and the result message no longer waits for
the full layout animation to report completion.

The mixture purchase, material and rupee costs, resulting effect, sounds, and
menu state are preserved.

Installation
Copy this mod folder into Eden's per-game mod directory, then enable it in the
game's Add-ons menu. Restart the game after changing the enabled state.

Compatibility
This patch is specific to Hyrule Warriors: Definitive Edition update 1.0.1 and
the Build ID listed above.
