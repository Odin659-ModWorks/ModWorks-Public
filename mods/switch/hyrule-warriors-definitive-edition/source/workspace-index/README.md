# Hyrule Warriors: Definitive Edition — mod history

This is the **workspace documentation index**, not an Eden add-on. The actual add-ons remain in their versioned folders. Do not place this documentation folder inside Eden's `load` directory.

Keep **one living history document per mod family**. Add dated entries to the same document when a test changes the answer; do not start a new note for every release candidate. Each history should say what the mod is meant to do, the game version and files it changes, how it was developed, what failed and why, what was verified, and what remains uncertain. Distinguish a user's gameplay report from a static file check. Preserve failed attempts because they prevent us from repeating mistakes.
