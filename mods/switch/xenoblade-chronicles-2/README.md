Game title ID: `0100E95004038000`.

- [Mods targeting game update 2.1.0](2.1.0/README.md)

The ModWorks builds currently target **2.1.0** in Eden. Nintendo lists **3.0.1** as the latest overall update; the newer update notes concern the Switch 2 Edition. A mod in the 2.1.0 folder is not automatically compatible with 3.0.1 or another executable build. See [Nintendo's update history](https://www.nintendo.com/en-za/Support/Nintendo-Switch/Game-Updates/How-to-Update-Xenoblade-Chronicles-2-1482905.html).
