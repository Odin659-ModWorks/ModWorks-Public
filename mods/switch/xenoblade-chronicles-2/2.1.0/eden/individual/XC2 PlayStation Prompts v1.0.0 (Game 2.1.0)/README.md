# PlayStation Prompts v1.0.0

For Xenoblade Chronicles 2 update 2.1.0. This release is finalized from the
user-approved RC4 package and replaces all earlier release candidates.

The menu and inline-text atlases now have a larger, centered Circle and Cross,
a vertically re-centered Triangle, the existing menu Square size, and centered
L1/R1 text in the circular shoulder icons. Create/Share uses only three
separate fan-shaped dashes with generous bottom spacing; Options uses three
horizontal dashes. Neither icon includes a physical-button capsule. The
salvage-timing atlas has separately centered and sized face symbols.

All four WILAY files were rebuilt in their original BC3/no-mipmap texture
format and decoded back. The decoded DDS files are byte-identical to their
pack inputs, and the user confirmed RC4's in-game appearance is working.
Install or remove only while Eden is closed, and do not enable an earlier
PlayStation prompt package alongside this release.
