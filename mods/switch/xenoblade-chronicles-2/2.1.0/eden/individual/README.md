# Individual Eden mods

This area will hold fixed Xenoblade Chronicles 2 (XC2) 2.1.0 mods for Eden. Each published package will identify its install path, required game and executable version, conflicts, and gameplay test status.

Planned categories include Core Crystal and Blade pulls, Common Blade quality, loot and collection, rewards, inventory, shop controls, visual changes, and controller prompts. These are search terms for work in progress, not claims that all packages are released.

For adjustable settings and combined builds, see the [Eden mod manager](../manager/README.md). No individual package has been published here yet.
