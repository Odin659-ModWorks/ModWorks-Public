# Eden mods for Xenoblade Chronicles 2 2.1.0

These Nintendo Switch mods target **Xenoblade Chronicles 2 (XC2)** game update **2.1.0** in the **Eden emulator**. Executable patches require build ID `F77F1559371C0EC6D50E78774AC59D95`.

- [Gameplay-confirmed individual mods](individual/README.md): fixed downloads and presets.
- [Mod manager](manager/README.md): still in development for custom values and compatible shared-file combinations.

Close Eden before installing, replacing, or removing a mod. Select only one option from each multiplier, quality-floor, or pickup-range family.
