# Eden mods for Xenoblade Chronicles 2 2.1.0

These Nintendo Switch mods target **Xenoblade Chronicles 2 (XC2)** game update **2.1.0** in the **Eden emulator**. Executable patches also require the documented build ID; the current work uses `F77F1559371C0EC6D50E78774AC59D95`.

- [Individual mods](individual/README.md): fixed downloads and presets.
- [Mod manager](manager/README.md): custom values and compatible combinations.

No finished public package is available yet. The pages below will gain downloads and installation instructions when each feature is verified. A future Ryujinx port will get a sibling `ryujinx/` folder under the same game version.
