# Xenoblade Chronicles 2 — game update 2.1.0

This folder is for mods tested against XC2 update **2.1.0**. Executable patches must also match their documented build ID; the current Eden work uses `F77F1559371C0EC6D50E78774AC59D95`.

- [Individual mods](individual/README.md): ready-made settings you can install separately.
- [Mod manager](manager/README.md): a portable tool intended to let you choose options and values, merge compatible changes, and build your own configuration.

Neither area has a finished public download yet. Each published mod will list its status, requirements, conflicts, and installation steps. Users must supply their own lawful game files where a patch builder requires them. Full extracted game data and saves are not distributed here.
